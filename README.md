### ✦ The Name, In Full

Three parts, one claim.

- **`TAI`** (The Great) — Absolute scale, preeminence, the foundation.
- **`KOR`** (Power/Core) — Will, agency, the active principle.
- **`IS`** (Enthroned/Is) — Realized, sovereign, established state.

> *Read together: **The Great Power, Enthroned.***
> <br/>This is our own construction, not a dictionary entry. We assembled the name and we hold ourselves to what it says.

### ✦ Getting Started

To run this project locally, follow these steps:

**1. Clone the repository**
```bash
git clone https://github.com/taikoris/taikoris-web.git
```

**2. Navigate to the project directory**
```bash
cd taikoris-web
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the development server**
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
